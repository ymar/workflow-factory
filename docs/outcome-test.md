# Uitkomsttest per pagina

Vier delen: **C** = klantcontext (branche of bedrijfstype), **P** = het probleem in de woorden van de koper, **V** = wat er verandert, **R** = het resultaat. Gecontroleerd op de H1, de intro en de meta description.
`✓` aanwezig, `~` impliciet of alleen in de intro, `-` hoort niet bij dit type pagina.

| Pagina | C | P | V | R | Oorzaken van generieke taal die zijn aangepakt |
|---|---|---|---|---|---|
| Homepage | ✓ | ✓ | ✓ | ✓ | FOMO (businessmodel als context in plaats van "B2B"), geen concurrentiewoorden, resultaat zonder cijfers (voorbeeld met "Stel:") |
| Meer aanvragen | ✓ | ✓ | ✓ | ✓ | Risicoschuw (benoemt wat het niet doet: geen ads of SEO), eigen taal |
| Sneller opvolgen | ✓ | ✓ | ✓ | ✓ | Intern (drie workflows in plaats van alles in een zin) |
| Klanten houden | ✓ | ✓ | ✓ | ✓ | Geen alignment-fout: dezelfde belofte als menu en homepage |
| Branches (overzicht) | ✓ | ✓ | ✓ | ~ | FOMO (vier branches, elk met eigen pagina) |
| Installatie en onderhoud | ✓ | ✓ | ✓ | ✓ | Geen onderscheid (datums van het vak), FOMO |
| Machinebouw | ✓ | ✓ | ✓ | ✓ | idem |
| IT-dienstverlening | ✓ | ✓ | ✓ | ✓ | idem, software-vermoeden alleen als vraag |
| Verhuur en lease | ✓ | ✓ | ✓ | ✓ | idem, software-vermoeden alleen als vraag |
| Workflows (overzicht) | ✓ | ✓ | ✓ | ✓ | Alignment: zelfde drie uitkomsten als het menu |
| Diensten | ✓ | ✓ | ✓ | ✓ | Interne complexiteit (drie stappen, Blueprint en Build als extra) |
| Opvolgscan | ✓ | ✓ | ✓ | ✓ | Risicoschuw (levert een pagina op, geen belofte) |
| Flow (bouwen) | ✓ | ✓ | ✓ | ✓ | Concurrentiewoorden ("opvolging die draait, ook als niemand eraan denkt") vervangen |
| 15 workflowpagina's | ✓ | ✓ | ✓ | ✓ | Vier-delenblok onder de H1, meta description als "Voor [context]: [resultaat], zodat/door [verandering]". De H1 is de naam van de workflow |
| HubSpot en ActiveCampaign | ~ | - | ~ | ~ | Naslagpagina's: context staat in de intro, niet in de H1 |
| Blueprint en Build | ~ | ~ | ✓ | ✓ | Extra's voor een ander probleem (positionering), niet herschreven |
| Contact, Over, Privacy, Teardowns, Velden en metingen | - | - | - | - | Geen verkoopclaim |

Nog niet af: de HubSpot- en ActiveCampaign-pagina's en Blueprint en Build volgen de test alleen deels.
